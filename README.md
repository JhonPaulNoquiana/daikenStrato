# Daikin × Strato Builders website

This workspace keeps the deployable website separate from source material and past exports.

| Folder | Purpose |
| --- | --- |
| `site/` | Website source, dependencies, public assets, and deployment settings |
| `assets/source-images/` | Original images supplied for the project |
| `docs/` | Original project brief and reference notes |
| `archives/deployments/` | Earlier deployment packages |
| `archives/previews/` | Earlier generated preview images |

Work on and deploy the website from `site/`. The `archives/` files are historical copies; they are not used by the running site.
